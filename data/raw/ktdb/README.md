# KTDB 2021 원본 계약

이 디렉터리는 KTDB 개인통행실태조사(2021년 기준) 원본 전용이다.

필수 입력 파일:

- `①개인특성.csv` — 개인 단위 조사 응답과 통행 기준일(`DATE`)
- `②이동특성.csv` — 통행 단위 장소·목적·시간·최대 10개 이동수단 응답
- `Code book.xlsx` — 변수 레이블과 코드값의 기준 문서
- `행정동코드_20210726(말소코드포함).xlsx` — 행정동 코드명 기준표

원본 파일은 읽기 전용으로 취급하며 내용·인코딩·컬럼명을 수정하지 않는다.
CSV는 CP949로 읽고, 실제 컬럼 의미와 코드값은 반드시 Code Book에서 확인한다.
다운로드 날짜와 SHA256은 파이프라인의 raw manifest에 기록한다.
