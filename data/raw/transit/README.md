# Transit Context 원본 데이터

이 디렉터리는 Transit Context reference를 만들 때 읽는 원본 입력 위치입니다.

현재 입력 파일:

- 한국철도공사 역 위치 정보 (2024-04-01)
- 서울교통공사 1~8호선 역사 좌표 (2025-08-14)
- 서울교통공사 서울 도시철도 열차운행시각표 (2026-06-16)

파일 내용과 인코딩은 그대로 보관하며, 처리 코드는 원본을 수정하지 않고
`data/processed/transit_context/`에 정규화 결과를 생성합니다. 원본 CSV는
공공데이터 이용 조건과 파일 크기 때문에 Git에 커밋하지 않습니다.
